# Pixel Pings

8-бітні звуки сповіщень для [Claude Code](https://claude.com/claude-code). Ти чуєш короткий чіптюн-сигнал, коли Claude завершив роботу або потребує тебе, і жодних нагадувань, якщо ти відійшов.

[English version](README.md)

## Що робить

| Звук | Коли грає | Характер |
|---|---|---|
| [`done`](sounds/done.wav) | Claude завершив роботу | швидке висхідне арпеджіо, як пройдений рівень |
| [`attention`](sounds/attention.wav) | потрібен дозвіл або відповідь | подвійний сигнал з інтонацією запитання |
| [`limit`](sounds/limit.wav) | роботу зупинено через ліміт | спадна фраза зі шумовим ударом, як втрата життя |

Claude Code також надсилає нагадування приблизно через хвилину очікування. Pixel Pings на нього не реагує, тож завершене завдання дає один звук, а не ще й повторний сигнал, поки тебе немає.

## Встановлення

У рядку введення сесії Claude Code в терміналі:

```
/plugin install pixel-pings --marketplace DaKoshin/pixel-pings
```

Введи `y`, щоб додати marketplace, а потім вибери область дії. Область користувача стоїть першою й охоплює всі твої проєкти.

З шелу:

```sh
claude plugin install pixel-pings --marketplace DaKoshin/pixel-pings
```

У застосунку для комп'ютера натисни **+** біля поля введення, потім **Plugins**, **Add marketplace** з `DaKoshin/pixel-pings`, а далі **Add plugin**.

## Налаштування

Попроси Claude своїми словами або виконай `/pixel-pings:setup`. Скіл уміє:

- програти звуки, щоб ти їх почув
- зробити їх гучнішими, тихішими або вимкнути
- прибрати банери терміналу від Claude Code, наприклад сповіщення iTerm2
- видалити старі звукові хуки, якщо все лунає двічі

Гучність задає змінна `PIXEL_PINGS_VOLUME` у блоці `env` файлу `~/.claude/settings.json`. `1` означає типову гучність, `1.5` на 50% гучніше, а `0` вимикає звук.

## Власні звуки

Усі звуки синтезує [`scripts/generate.py`](scripts/generate.py) лише за допомогою стандартної бібліотеки Python. Зроби fork репозиторію, зміни ноти в `SOUNDS` і запусти:

```sh
python3 scripts/generate.py
```

## Вимоги

| Платформа | Стан |
|---|---|
| macOS | Перевірено. Використовує вбудований `afplay`. |
| Linux | Має працювати з `paplay`, `ffplay` або `aplay`, але не перевірялося. `aplay` ігнорує налаштування гучності. |
| Windows | Поки не підтримується. |
